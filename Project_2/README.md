# Mini Social Media App

A full-stack Mini Social Media Application built using HTML, CSS, JavaScript, Django, and SQLite.

## Features

* User Profiles
* Create Posts
* Comment System
* Like Functionality
* Follow/Unfollow System
* Django Admin Panel
* SQLite Database Integration

## Tech Stack

### Frontend

* HTML
* CSS
* JavaScript

### Backend

* Django (Python)

### Database

* SQLite
